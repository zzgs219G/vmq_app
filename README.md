# V免签监控

个人收款监控 + 自动发卡的 Android 端。配合服务端仓库 `vue-faka` 使用。

## 它是怎么工作的

买家在你的发卡网下单，系统生成一个带随机浮动金额的订单（比如 ¥28.37）；买家扫码付这个精确金额；本应用监听手机上的微信/支付宝收款通知，抓到金额后推送给服务端；服务端按金额匹配订单并发卡密。

**金额就是订单标识**，这是整套系统的核心设计。

## 功能

| 页面 | 内容 |
|---|---|
| 监控 | 通知权限状态、保活状态、快捷测试、运行日志 |
| 账本 | 收款统计、待确认队列、流水记录、手动补录 |
| 订单 | 服务端订单列表、疑似漏发比对、重推 |

## 快速开始

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug        # 调试包
./gradlew assembleRelease      # 签名正式包
./gradlew testDebugUnitTest    # 单元测试（29 个）
```

⚠️ 项目路径不能含非 ASCII 字符，否则 Kotlin 编译器会报「源文件全部找不到」。详见[部署与配置](docs/部署与配置.md)。

## 云端构建

GitHub Actions 手动触发，或打 `v*` 标签。`release.keystore` 已入库，无需配置 Secrets。

## 注意

本项目为自用工具，与商业发卡平台无关。核心对账依赖个人收款码的金额通知，不接入任何第三方支付网关。
